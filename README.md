# Кана

Личный тренажёр хираганы на русском: 46 базовых знаков, 10 уроков, чтение, задания на слух, ввод ответа, повторение ошибок и сохранение прогресса.

## Запуск локально

Нужен Python 3. Зависимостей и сборки нет.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://localhost:4173. Для прогресса localhost и 127.0.0.1 — разные адреса: использовать один и тот же.

## GitHub Pages

Приложение находится в `dist/`. Workflow **Test and deploy Pages** проверяет тесты и публикует эту папку при push в `main` или ручном запуске.

Один раз включить: **Settings → Pages → Build and deployment → Source → GitHub Actions**. После этого запустить workflow повторно, если первый запуск не прошёл настройку Pages.

Все пути в приложении относительные; приложение работает из подкаталога репозитория. Service worker ограничен этим подкаталогом.

## Google Sheets

[Пошаговая настройка](dist/google-setup.html) также доступна внутри приложения: значок облака → «Инструкция настройки».

1. Создать Google Cloud project и включить **Google Sheets API**, **Google Drive API**.
2. Настроить Google Auth Platform: External, свой аккаунт в Test users, scope `https://www.googleapis.com/auth/drive.file`.
3. Создать OAuth Client типа **Web application**. Authorized JavaScript origins: `https://hb3p8.github.io`, `http://localhost`, `http://localhost:4173`. Пути `/jap-learn/` в origins не указывать. Client Secret не нужен.
4. Вставить публичный Client ID в приложении: облако → «Настройка». Либо добавить repository **Variable** `GOOGLE_CLIENT_ID` и повторно запустить workflow: он запишет ID в публичный `dist/config.mjs` перед публикацией.
5. Нажать «Подключить Google» и пройти авторизацию самостоятельно.

Таблица **«Кана — прогресс»** создаётся после первого входа. Доступ ограничен файлами приложения через `drive.file`; таблица остаётся личной. На другом устройстве войти в тот же аккаунт, используя тот же OAuth client/project.

Access token находится только в памяти страницы. После перезагрузки или истечения сеанса потребуется повторный вход. Секреты и service-account JSON не нужны и не должны попадать в репозиторий.

Ответы сразу сохраняются в localStorage. Во время действующего подключения снимки отправляются в Sheets через 8 секунд после последнего изменения. Ошибки сети не прерывают занятия; есть ручная синхронизация. Журнал снимков сохраняет связи версий; независимые изменения устройств приводят к выбору версии, а не к тихой перезаписи. Выбранная версия объединяет ветки, старые строки сохраняются. Формат листа `Сохранения`: `id`, `parents`, `device`, `saved_at`, `state_json`.

Локальный и опубликованный сайт имеют разные хранилища. Для первого переноса: **Прогресс → Сохранить файл** на старом адресе, затем **Загрузить прогресс** на новом. После этого подключить Google.

Без Client ID приложение полностью работает локально; облачная синхронизация ожидает настройки. Настоящая авторизация и запись в Google требуют проверки владельцем после настройки. API и разрешение `drive.file`: [Google Sheets scopes](https://developers.google.com/workspace/sheets/api/scopes), [Google OAuth token model](https://developers.google.com/identity/oauth2/web/guides/use-token-model).

## Озвучка

56 встроенных MP3: 46 отдельных знаков и 10 слов. Японский синтез речи **Kyoko**, команда macOS `say -v Kyoko -r 125`, затем конвертация в MP3 через FFmpeg. Аудио курсов в приложение не переносилось.

## Проверки

Node.js 24 или новее:

```sh
node --test tests/*.test.mjs
```

Тесты проверяют учебную логику, сохранение и повторение ошибок, восстановление состояния, ветвление снимков между устройствами, разрешение конфликтов, ограниченное обнаружение таблиц, запросы API, проверку подтверждения записи и ошибки авторизации. Тесты Google API используют подставные ответы; они не выполняют вход в реальный аккаунт.

## Файлы

- `dist/content.mjs` — знаки, уроки и произношение.
- `dist/engine.mjs` — упражнения, интервалы, XP и валидация состояния.
- `dist/app.mjs` — интерфейс и браузерное хранение.
- `dist/sync-core.mjs` — снимки, связи версий и выбор направления синхронизации.
- `dist/google-sheets.mjs` — REST-клиент Drive/Sheets.
- `dist/google-sync.mjs` — вход Google, синхронизация и состояния подключения.
- `dist/config.mjs` — публичная конфигурация OAuth.
- `dist/privacy.html` — данные и доступ.

После 3 верных ответов подряд знак помечается закреплённым. Следующие повторения назначаются через 5 минут, 1, 3, 7, 14 и 30 дней. Ошибка возвращает знак через несколько заданий и оставляет его в списке ошибок до двух верных ответов подряд.
