# Кана

Личный тренажёр хираганы на русском: 46 знаков, 10 уроков, чтение, задания на слух, ввод ответа, повторение ошибок и сохранение прогресса.

## Приложение

Сайт публикуется из `dist/` в GitHub Pages через `.github/workflows/pages.yml`. Изменения `main` проходят тесты и публикуются автоматически. Зависимости для статического сайта не нужны.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://localhost:4173. Адреса localhost, 127.0.0.1 и GitHub Pages имеют разные хранилища браузера.

## Синхронизация Cloudflare Workers + D1

Сайт остаётся на GitHub Pages. Отдельный Worker принимает авторизованные запросы и хранит снимки прогресса в D1. Сервер не требует VPS. Доступ защищён случайным ключом из 32 байт; на сервере хранится SHA-256 хеш как Cloudflare Secret `SYNC_KEY_HASH`.

На каждом устройстве: значок облака → **Подключить устройство** → адрес Worker и ключ → **Сохранить и подключить**. Адрес подставляется из публичного `dist/config.mjs`. Ключ берётся из закрытого локального файла `.local/sync-key.txt` или `.local/cloudflare-connection.json`. После первого подключения ключ сохраняется в браузере, синхронизация продолжается после перезапуска страницы.

[Инструкция подключения](dist/sync-setup.html).

Ответы сразу сохраняются локально. Через 5 секунд после последнего изменения снимок отправляется в D1. Возвращение сети или фокуса запускает проверку. Без сети занятия продолжаются. Каждая версия имеет UUID и список исходных версий; конкурентные изменения устройств сохраняются обеими ветками. Выбор версии создаёт новый снимок, объединяющий ветки; история не удаляется. Повторная отправка того же UUID идемпотентна.

Для переноса старого прогресса с localhost: **Прогресс → Сохранить файл**, затем **Загрузить прогресс** на опубликованном сайте. JSON прогресса не содержит ключ подключения.

## Развёртывание Worker

Node.js 24+, npm и бесплатный аккаунт Cloudflare:

```sh
npm ci
npx wrangler login --scopes account:read user:read workers_scripts:write d1:write
npm run cloudflare:setup
```

Скрипт:

1. Сохраняет случайный ключ в `.local/sync-key.txt` с правами 0600.
2. Создаёт или находит D1 `jap-learn-progress`, применяет миграции.
3. Развёртывает Worker `jap-learn-sync`.
4. Устанавливает хеш ключа в Cloudflare Secrets. Уже установленный чужой ключ автоматически не заменяет.
5. Проверяет чтение с ключом и отказ без ключа.
6. Записывает публичный URL в `dist/config.mjs`, а закрытые параметры подключения — в `.local/cloudflare-connection.json`.

После этого отправить изменение `dist/config.mjs` в GitHub. Необязательно: repository Variable `CLOUDFLARE_SYNC_URL` может переопределить URL при сборке Pages. Ключ в repository Variables или в `dist/` не размещается.

Если в аккаунте несколько Cloudflare accounts, указать нужный `CLOUDFLARE_ACCOUNT_ID` перед запуском. Скрипт сам принимает единственный аккаунт, когда выбора нет. Если аккаунт ещё не имеет `workers.dev` поддомена, сначала настроить его в Cloudflare Dashboard.

Не удалять `.local/sync-key.txt`: этот ключ нужен существующим устройствам и повторному развёртыванию. Для намеренного отзыва ключа владелец заменяет `SYNC_KEY_HASH` и передаёт новый ключ своим устройствам.

## Локальная проверка Worker

```sh
node scripts/setup-cloudflare.mjs --local
npm run worker:dev
```

По умолчанию API: http://localhost:8787. Если порт занят: `npm run worker:dev -- --port 8788`. Локальные секреты находятся в игнорируемом `worker/.dev.vars`, база — в игнорируемом `.wrangler/`.

## Проверки

```sh
npm test
```

Тесты проверяют учебную логику, сохранение незаконченных занятий, повторение ошибок, ввод и импорт, восстановление на другом устройстве, конфликт версий, отключение во время запроса, проверку ключа и CORS. Тесты Worker выполняют настоящую SQL-схему в SQLite; HTTP-интеграция дополнительно проверена в локальном workerd с D1.

## Озвучка

56 встроенных MP3: 46 знаков и 10 слов. Японский синтез речи Kyoko, macOS `say -v Kyoko -r 125`, затем FFmpeg. Аудио учебных курсов не переносилось.

[Irodori Starter, Marugoto Plus и Tae Kim](docs/learning-sources.md). Оригиналы скачаны отдельно для личного изучения и не включены в репозиторий. Упражнения и объяснения подготовлены самостоятельно.

## Основные файлы

- `dist/content.mjs` — знаки, уроки, подсказки произношения.
- `dist/engine.mjs` — упражнения, интервалы, XP и валидация.
- `dist/app.mjs` — интерфейс и localStorage.
- `dist/sync-core.mjs` — снимки, связи версий и решение о синхронизации.
- `dist/cloud-sync.mjs` — сохранение, восстановление, состояния подключения.
- `dist/cloudflare-store.mjs` — HTTP-клиент.
- `worker/index.mjs` — защищённый Worker API.
- `worker/migrations/` — SQL-схема D1.
- `scripts/setup-cloudflare.mjs` — развёртывание.

Знак закреплён после 3 верных ответов подряд. Повторения назначаются через 5 минут, 1, 3, 7, 14 и 30 дней. Ошибка возвращает знак через несколько заданий и оставляет его в списке ошибок до двух верных ответов подряд.
