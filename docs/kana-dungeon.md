# Подземелье хираганы

Открыть: https://jap-learn-sync.jap-learn.workers.dev/#dungeon

## Текущая версия

- Три случайно генерируемых этажа по пять монстров, связные комнаты и коридоры, видимость и память карты.
- Пошаговое движение, шесть единиц здоровья, зелье на +2, лестница после зачистки. Стрелки на компьютере, экранные кнопки на телефоне. Таймера нет.
- Каждый монстр — обычный знак хираганы без постоянного цвета или другой подсказки к чтению. Чтобы победить, нужно ввести чтение, а не выбрать его из вариантов. Принимаются используемые приложением варианты латиницы и русские приблизительные чтения.
- Можно атаковать любого видимого монстра. Верный ответ защищает от атак в этот ход; при движении рядом с монстром можно получить удар. Ошибка отнимает одно здоровье.
- По умолчанию — только изученные знаки, с приоритетом ошибок и менее уверенных букв. Для начала с нуля можно явно выбрать ряд; все 46 — отдельная настройка.
- После ошибки или подсказки показаны правильное чтение и звук. Исправление позволяет продолжить игру, но не повышает знание буквы и не приносит XP. Ошибочный знак возвращается на следующем этаже, а также остаётся в обычном повторении до самостоятельных успешных ответов.
- Самостоятельный верный ответ даёт 3 XP и использует общий механизм учёта хираганы. Игра не помечает учебные уроки пройденными. Забег, карта, ошибки и позиция автоматически сохраняются локально и в прежнее облако.
- Результат забега не является проверкой долговременного запоминания: для этого нужен отдельный повтор через день.

Это самостоятельная небольшая реализация с визуальным ориентиром на ASCII-roguelike; код и ресурсы Brogue не используются.

Источники описывают механики игр, а не доказывают эффективность обучения. Предложения ниже — решения для этого личного тренажёра.

## Развитие по приоритету

1. **Комнаты похожих знаков.** Серии ぬ/め, れ/ね/わ, る/ろ, выбираемые по собственным ошибкам. После ошибки — короткое сравнение отличающихся деталей, затем снова самостоятельный ввод через несколько других заданий. Цель: различать форму, а не запоминать случайный цвет или позицию врага.
2. **Отложенный реванш.** Ошибки сегодняшнего забега возвращаются завтра в коротком этаже без подсказок. Отдельно считать точность первого ответа через день, а не число убитых монстров. Это будет понятнее показывать, что сохранилось в памяти.
3. **Монстры на слух.** Сначала звучит мора; игрок выбирает соответствующий знак. Отдельный режим различает направление «вижу → читаю» и «слышу → узнаю знак». Он не должен притворяться проверкой собственного произношения: микрофона и распознавания речи здесь нет.
4. **Слова из известной хираганы.** После освоения букв — монстры あい, いけ, ねこ и другие короткие слова, полностью состоящие из изученных знаков. Нужно прочитать всё слово; затем показывается его значение и запись. Это переносит навык с изолированной буквы на чтение.
5. **Короткие задания Genki.** Лестница открывается после сборки знакомой фразы или понимания одного вопроса из уже пройденного занятия. Не добавлять новую грамматику без объяснения ради игрового препятствия.
6. **Катакана и смена начертания.** Сначала отдельные забеги катаканы; позже пары хирагана/катакана одного звука. Обычный печатный шрифт остаётся основным. Другие шрифты — явно включаемая тренировка после уверенного чтения.

Постоянное развитие экипировки, обязательные серии ежедневных входов и гринд уровней сейчас не нужны. Победу должен определять навык чтения; скорость можно добавить позднее как отдельный необязательный показатель для уже знакомых букв.
