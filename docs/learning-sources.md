# Учебные источники для модуля хираганы

Скачано 25 октября 2026 года. Оригиналы сохранены для личного изучения и сверки. Приложение использует собственные задания и объяснения; эти файлы не входят в публикуемый каталог приложения.

## Irodori Starter, русская версия

- Автор: The Japan Foundation.
- Официальный индекс: https://jpfmw.ru/ru/yaponskij-yazyik/uchebnyie-materialyi-irodori/irodori-nachalnyij-uroven/
- Локально: `irodori/starter-01.pdf` … `irodori/starter-18.pdf`, вводные материалы и словарь.
- Разобраны глава 1, стр. 14–16 (таблица хираганы, разные шрифты, долгие гласные, двойные согласные, ввод на клавиатуре), глава 2 (катакана и фонетическая практика), инструкция по использованию.
- Для разработки взяты принципы: слушать → различать → читать → применять, связывать звук с написанием; дополнительно тренировать письмо и чтение вне основного курса.
- Условия: https://www.irodori.jpf.go.jp/en/privacy.html, сохранены в `irodori-privacy.html` и `.txt`. Разрешено хранение на личных устройствах, самостоятельное обучение и использование на занятиях. Производные материалы, публикуемые для работы с Irodori, должны быть бесплатными и указывать источник; запрещено использовать части курса в новых материалах, совсем не связанных с Irodori.
- Аудио Irodori в приложение не переносится: приложение имеет собственные упражнения и отдельную озвучку. Скачанные оригиналы сохранены отдельно.

## MARUGOTO+ Starter A1: Hiragana

- Автор: The Japan Foundation, Japanese-Language Institute, Kansai.
- Источник: https://a1.marugotoweb.jp/en/hiragana.php
- Локально: `marugoto-hiragana.html`, удобный текстовый снимок `marugoto-hiragana.txt`.
- Разобраны таблица базовых слогов, ряды гласных и согласных, дакутэн/хандакутэн, сочетания с маленькими я/ю/ё; проверено наличие отдельных аудиопримеров каждого знака на официальном сайте.
- Для разработки: учить небольшими рядами, сопоставлять символ со звуком, отличать основную таблицу от производных сочетаний.
- Условия: https://marugotoweb.jp/en/site_policy.php; локально `marugoto-policy.html` и `.txt`. Авторские права сохранены, воспроизведение допускается для личного использования; цитирование для образовательных целей в законном объёме с указанием источника. Готовые тексты, изображения и MP3 не включаются в публикуемое приложение.

## Tae Kim: Japanese Grammar Guide и Hiragana

- Автор: Tae Kim.
- Бесплатный полный PDF: https://www.guidetojapanese.org/grammar_guide.pdf
- Локально: `tae-kim/grammar-guide.pdf`, извлечённый текст `tae-kim/grammar-guide.txt`.
- Актуальная веб-глава: https://guidetojapanese.org/learn/grammar/hiragana ; локально `tae-kim-hiragana.html` и `.txt`.
- Разобран раздел The Writing System / Hiragana, базовая таблица, удвоение согласных и долгие гласные; сопоставление печатной/рукописной формы.
- Для разработки: звук важнее приблизительной транскрипции; не считать русскую подсказку точной фонетической записью. Отдельно объяснять う, し, ち, つ, ふ, ん. Указывать, что き и さ могут выглядеть иначе при письме от руки.
- Лицензия Grammar Guide: Creative Commons Attribution–NonCommercial–ShareAlike 3.0 US. Подтверждение на странице https://guidetojapanese.org/learn/grammar (локально `tae-kim-license.html` и `.txt`). Дословные тексты и авторские упражнения не переносятся в приложение; используются общедоступные факты о языке и собственная структура заданий.

## Рекомендации к собственным заданиям

1. Первая группа — あ・い・う・え・お. Сначала показать и дать послушать каждый знак, затем угадывание звука по знаку, знака по звуку и чтение без вариантов ответа.
2. Следующая группа — か・き・く・け・こ. Повторять с гласными, не вытесняя их полностью новым материалом.
3. Слова для постепенного чтения: あお (синий/сине-зелёный цвет), いえ (дом), うえ (верх), え (рисунок), かお (лицо), かき (хурма), いけ (пруд). Учитывать омонимию かき; смысл показывать явно.
4. После ошибки показать правильный знак со звуком и короткой подсказкой, затем вернуть вопрос после нескольких других заданий. Не засчитывать единичный выбор как уверенное освоение.
5. Долгие гласные и маленькую っ вводить отдельным шагом после уверенного чтения базовых знаков.
6. Для самостоятельного письма подходят бумага и ручка; распознавание рукописного ввода не требуется первому модулю.

Полный список файлов, их размеров, исходных URL и SHA-256 — `manifest.json`. Исходники нужно сохранять отдельно от публичных ресурсов приложения.

## Genki I — «Знакомство», второе издание

Пользователь предоставил локальный комплект `Genki - An Integrated Course in Elementary Japanese [Second Edition] - 2011` и разрешил размещение материалов в личном приложении с доступом по ключу. Издатель: The Japan Times. Первый модуль соответствует темам главы 1 (стр. 38–57): знакомство, 28 выбранных слов/выражений, は / です / か / の, числа, время, возраст и два диалога. Русские объяснения и задания подготовлены для этого тренажёра. PDF первого тома является сканом; содержание и диалоги сверены визуально.

Оригинальные записи K01-01…K01-07 и K01-11 (включая варианты диалогов для повторения) копируются только в игнорируемый `dist/assets/genki/` и в закрытую сборку Worker. В публичный Git и GitHub Pages эти файлы не входят. Все 28 карточек слов используют отдельные фрагменты оригинальных K01-05 и K01-06. Границы сверены со словарём на стр. 40–41, распознаванием реплик и паузами записи. `scripts/genki-word-clips.mjs` фиксирует интервалы и SHA-256 исходников. Записи нормализованы до пика −2 dBFS; медленные варианты сделаны через `atempo=0.8`, без изменения высоты голоса. Путь `words-original-v1` исключает старую синтетическую озвучку из кэша. Для полного словаря, часов и диалогов доступны целые оригинальные дорожки. Персональный импорт на каждом устройстве не требуется.

## Текущая озвучка хираганы

С 25 октября 2026 года все 46 базовых знаков используют индивидуальные записи [Marugoto Plus — Hiragana](https://a1.marugotoweb.jp/en/hiragana.php), включая отдельное соответствие を → wo.mp3 и ん → n.mp3. Source: The Japan Foundation, Japanese-Language Institute, Kansai.

По [политике источника](https://marugotoweb.jp/en/site_policy.php) копии предназначены только для частного использования. Они хранятся в игнорируемом `dist/assets/kana-audio/marugoto-v1/` и публикуются только за прежним серверным ключом. Ни Git, ни GitHub Pages эти записи не содержат.

Подготовка: `node scripts/prepare-kana-audio.mjs`. Скрипт сверяет японский знак с MP3 в официальной таблице, сохраняет исходники и контрольные суммы в `.local/kana-audio-sources/`, выравнивает пиковый уровень до −2 dBFS и делает версии 0,8× фильтром atempo без изменения высоты голоса. Паузы и начала звуков не обрезаются. Формат — mono MP3, 48 kHz, 128 kbps. Проверка: `node scripts/check-kana-audio.mjs` — декодирование, непустой сигнал, отсутствие перегрузки и длительность обеих версий для всех 46 знаков.

Новый путь файлов исключает использование старых синтетических слогов из кэша. Обычная запись используется везде, в том числе в подземелье. Кнопка «Медленно» есть в карточках, азбуке, заданиях на слух и обратной связи подземелья. Только десять примеров слов в результатах уроков хираганы используют прежний синтез Kyoko. Все слова и диалоги Genki используют оригинальные записи.
